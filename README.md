# NeverLost

Companion web app for Hannah’s homemade LED + AirTag school keychain.

**Live app:** https://evinstance1-cloud.github.io/neverlost/

This is a static web build of the Expo app, hosted on GitHub Pages. The native iPhone app (Find My deep link, widgets, TestFlight / App Store) is separate and still needs an Apple Developer account.

Open the link on an iPhone in Safari. Data stays in the browser on this device.
